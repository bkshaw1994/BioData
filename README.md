## 🛠️ Interactive Features

- **Built-in Data Customizer (`Customize Data`):**
  - Allows editing Mother's name, College/University name, Father's occupation, Brother's details, contact numbers, and horoscope directly in the browser.
  - Automatically saves to `localStorage` with a 1-click **"Reset to Original"** option.
- **Download / Print Bio-Data (`window.print()`):**
  - Tailored `@media print` stylesheet with dedicated `PrintBioData` component.
  - Automatically hides navigation, interactive buttons, galleries, and floating widgets.
  - Exports a crisp, elegant, 1-to-2 page A4 PDF formatted for formal family sharing.
- **Share via WhatsApp:**
  - One-click share with a polite, respectful pre-filled matrimonial invitation message and direct WhatsApp link.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation & Run

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview production build
npm run preview
```
